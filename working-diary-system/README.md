# Deprecated v1 Scripts

This directory contains the original v1 script-based implementation. It is kept for historical reference only and is not the supported installation path.

Use the current Python package instead:

```bash
pip install claude-diary
working-diary init
working-diary install --force
```

For Codex skills:

```bash
working-diary init --codex-only
working-diary install --force --codex-only
```

The maintained implementation lives under `src/claude_diary/`. See the root `README.md` or `README.en.md` for current usage.
